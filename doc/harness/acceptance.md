# 浏览器功能验收

本清单补充自动检查，不指定 UI 风格。根据改动选择相关场景，并记录实际结果；发布前的较大游戏变更应覆盖完整对局。没有执行的项保留未勾选。

## 准备

- [ ] `npm ci`、`npm run check` 通过，记录报告位置和时间。
- [ ] `npm start` 后通过 HTTP 打开本地地址，入口、模块、CSS 和图片无本地加载错误；浏览器无脚本异常。
- [ ] 对依赖发布路径的变更，同时检查生成站点在 `/air-poker/` 子路径下的真实浏览器行为。

## 开始、导航与语言

- [ ] 从首页进入正式局，开局过场后可选目标；规则或档案可打开、关闭。
- [ ] 中文和英文切换后静态、候选、结果文案更新；目标、牌面、AIR 和阶段保持不变。
- [ ] 对局中只读查看规则后回到原阶段；每次玩家行动计时不重复，不被语言或规则查看重置。
- [ ] 重开恢复每方总资源 25 罐、已开 1 罐、未开 24 罐、初始阶段与空弃牌；旧过场、旧构造和旧下注计时器不再修改新局。

## 选牌、下注与结算

- [ ] 可解目标出现一至三个合法五张候选，可切换和推荐；无解数字仍可选，显示失败说明与主动失败入口。
- [ ] 锁定成手进入下注，重复点击不能重复扣底注；冻结后不能继续修改成手。
- [ ] 过牌、跟注、加注、弃牌、全押只在合法时可用；一人过牌仍继续，面对加注不可过牌，跟注后换人继续。加注非法或超过输入范围时有反馈且资金不变化。
- [ ] 资金显示与引擎一致，双方可匹配资源不足时不会负数；全押只投入实际可匹配金额，仍遵守先跟齐后的半池上限。
- [ ] 五张数字牌逐轮消费、不补牌；同值不同位置分别计数；已用实体牌不出现在后续候选中。
- [ ] 摊牌后重复点击下注不再次结算；下一回合只推进一次。
- [ ] 五轮完成或不能继续下注时进入耐息，可等待或快进；胜负与实际供气及缺氧宽限结束一致，同刻耗尽为平局，不能只比较未开余额。

- [ ] 选择前不公开 CPU 数字与成手；选择后只公开 CPU 本轮数字与剩余数量，直到摊牌才显示五张私牌。
- [ ] 结束原因与实际已完成回合数一致；单方失败、双方同轮重做、双无解退款转耐息均有可理解提示，不重复扣底注或增加回合数。

- [ ] 首轮小数字先动、后续首动交替；CPU 等待期间玩家按钮禁用；CPU 跟注/加注/弃牌与公开投入一致。

- [ ] 构造有 60 秒时限；主动放弃或超时保留该方实体牌，单方失败只输实际底池，不追加灾厄。
- [ ] 当前供气按时间减少，300 秒换罐，仅未开罐能下注；回合推进不额外扣费，零未开罐仍能使用当前供气。
- [ ] 呼吸更新期间加注输入与焦点保留；换罐导致资源减少时，未匹配多余投入退回且应跟额刷新。

## 浏览器边界

- [ ] 每次玩家行动 30 秒，无应跟额超时过牌、有应跟额超时弃牌，最多一次；旧按钮和回调不能修改下一行动或新局。
- [ ] 后台停留后回到页面，计时反映实际经过时间；页面生命周期恢复后无重复事件或遗留计时器。
- [ ] 浏览器存储不可用时仍能开始、切换语言和结束游戏，失败不阻断主流程。
- [ ] 手机窄屏与桌面都能选择候选、操作下注、关闭规则和重开；页面不存在遮挡关键操作的内容或隐藏容器占位。
- [ ] 键盘能到达并触发主要按钮，控件名称可理解，禁用操作不改变状态。
