# 首页访问统计

2026-10-24：按用户要求，在首页底部显示全站累计访问次数。

使用 [Hits 官方图片接口](https://hits.sh/docs/)，无需账号、密钥、远程脚本或后端。Context7 工具在本次会话不可用，接口参数直接核对官方文档。图片使用灰黑配色与 `PV` 标签，页面文案支持中英文。

## 统计边界

- `browser/visit-counter.js` 以自身模块的上级目录确定站点根地址，使用域名及项目路径作为 key，兼容 GitHub Pages 子路径，避免同域名多个仓库混算。首页别名、查询参数和锚点不改变 key。
- 一次整页加载只设置一次图片地址；计数节点位于 `#pageContent` 外，切页、语言切换和游戏重开不会再次请求。公网 HTTPS 才启用，本地 HTTP、回环及常见内网地址不请求服务。
- PV 统计图片加载请求，不去重为独立访客，也不保证与真实浏览人数相同；缓存、拦截、重复访问和服务可用性会影响结果。不能恢复接入前的历史访问，更换域名或项目路径会开启新计数。
- 加载中、本地预览和不可用具有文字状态。失败或 8 秒超时后不自动重试，不显示虚假的 0，不阻断游戏；非缓存离开页面清理尚未完成的监听与计时器，bfcache 保留原请求与回调，恢复不重计。
- 外部请求仅为计数图片，采用 `no-referrer`，不发送对局或本机记录。服务方仍能收到常规图片请求的网络信息。

## 验证

2026-10-24 的 `npm run check` 全部通过：语法、架构、93 项测试、格式、发布产物，以及根路径与 `/air-poker/` 的 HTTP 资源检查。报告位于忽略目录 `output/harness/latest.json`。

真实浏览器使用 Codex 内置 Chromium，桌面视口约 1280 × 720，并使用 390 × 844 的 iframe 视口检查窄屏排版；没有在实体手机上测试。
