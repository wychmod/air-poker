## 实现边界

- app.js 负责事件委托、导航、真实时钟、偏好、对话框和只读播放。未完成局离开或重开需界面确认，避免误触丢失当前局。
- ui/render.js 组合页面，保留输入与键盘焦点；只在语言变化时重新生成规则正文。普通呼吸脉冲只更新供气。
- ui/battle.js 仅渲染公开快照。摊牌额外读取本轮完整记录，区分累计投入、收款、先前退款、呼吸与烧毁。
- ui/tutorial.js 为独立练习状态，没有正式游戏的引用、计时器和 dispatch；示例用当前规则函数验证。
- ui/review.js 只读打开时记录，播放按事件序号进行。拖动提交选择，不重跑 AI，不派发正式动作。
- browser/scene-motion.js 用相邻公开快照识别已接受的目标、锁定、支付、摊牌和灾厄。支付使用真实 paid 事实，不把呼吸余额减少当作下注。
- Canvas 统一调度，像素倍率上限 2，隐藏时停止绘制；系统减少动态效果优先于应用开关。停止动画不停止真实对局。
- 所有卡牌、数字、按钮、墨弧、气泡与资金路径由 HTML/CSS/JS/SVG/Canvas 实时呈现，不预生成视频帧。

## 素材与采用方式

首页/介绍使用原有无 UI 生成背景；左右人物通过遮罩做低幅整体运动，桌面中央保持稳定。教学、胜利、失败使用用户明确指定的本地图片，复制到 assets/generated/air-poker-v2 以纳入现有运行目录；来源见该目录 README。裁切、灰阶与框线由 CSS 完成，没有把带旧按钮的整页效果图当作可操作界面。

人物目前为整体/遮罩层运动；独立发丝、表情、手掌关节以及更高分辨率胜利人物仍是后续素材增强项。本轮没有远程发布。

## V2.1 白纸黑墨修订

用户确认首页与内部纸白页面应保持统一，并批准按这个方向改进。本次范围是视觉与动效呈现，不改变游戏规则、时限、供气、资金或结果判定。

### 修订范围

- P01 首页和开局短过场转为纸白底，保留双人对峙、圆桌、人物低幅运动、气泡和水纹；标题与主按钮使用墨黑，灰阶线稿保持水下漫画气氛。
- P02 介绍、P03 教学、P04 对战与 P08 复盘沿用纸白内容区，统一导航、卡牌、操作区与浮层的边线、灰阶和纸面层次；完整牌面与真实数值持续清晰。
- P05 胜利扩大留白并保留抬手与墨弧；P06 失败通过局部密网点、近景与少量暗红表达压力；P07 平局保持对称浅纸与水平水纹。
- 页面之间延续同一底色，开局与页面转场使用墨线分镜和浅灰水纹，避免整屏深色突变。减少动态效果时仍保留清楚的操作状态。
- 深色 manga-mode-home.png 继续作为双人、圆桌与标题层级参考；纸白 manga-introduction-background.png 决定本次色调和留白。AGENTS.md、README.md 与 V2.1 规划同步此方向。
