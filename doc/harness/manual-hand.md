# 自由成手修复

## 问题与范围

用户无法逐张组牌：当前界面只提供三个整手推荐。引擎已有 submit-hand 与 used-card 校验，修复集中在界面草稿、事件、动效与说明，保留现有下注和结算规则。

## 实施约定

- 从 52 张标准实体牌自由选取五张，推荐只负责填入可编辑草稿。
- 草稿按 sessionId / attemptId 隔离；新尝试清空，语言切换、呼吸更新、查看规则保留，不重置 60 秒截止时间。
- 已用牌可见且可选，明确提示锁定会导致该次成手失败；同点数不同花色分别判断。
- 确认通过引擎 submit-hand；失败在确认时记录，首次尝试仍按现有下注流程结算，双方失败同轮重做。
- 选牌和锁定动效来自实际草稿；不触发规则动作，尊重减少动态偏好。

## 验收目标

- 合法非推荐成手可锁定；跨轮复用实体牌会失败且不消耗失败手，资金守恒。
- 五个选牌槽、点数和、失败原因、花色筛选与推荐编辑在中英文和窄屏可用。
- 超时旧按钮失效，重复提交不重复扣款；对手手牌摊牌前保持隐藏。

## 2026-11-07：快速推荐区分牌型

用户希望三个推荐各不相同。目前候选仅按实体牌去重，同一点数组合更换花色仍会占据多个位置。本轮将玩家推荐改为至多三种不同牌型，每类取当前最强的一手，按牌力排列；只有一两种合法牌型时按实际数量显示。保留最强首选、五张不同未用实体牌和正确点数和，推荐仍只填入可编辑草稿。

计划与依赖：先为引擎快照增加可复现的牌型去重断言，再在 cards 内复用候选枚举生成玩家推荐；引擎初次构牌和同轮重做使用新入口，AI 的原有候选预算、排序和策略不变。最后更新推荐说明与架构文档，运行完整工程检查及桌面/手机浏览器验收，记录实际结果。

验证与结果：

- `npm run check` 通过，190 项自动测试；语法、架构、格式、构建、资源预算和 HTTP 检查全部通过，报告为 `output/harness/latest.json`。
- `npm run check:browser`：76 项通过、2 项由 Playwright 配置跳过，无失败。新增浏览器用例覆盖中英文、三个推荐分别填入、完整草稿可编辑、移除后无法锁定、复选后可锁定，以及 320 / 390 px 手机模拟与 1280 px 桌面子路径。未执行实体手机或 Safari。
