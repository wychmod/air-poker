## 玩法图示交互调整

用户要求移除“看演示 / 重播”按钮，改成鼠标悬停播放。三个图示卡片改为悬停或聚焦时运行一次 CSS 动画，移开或失焦后复位；键盘 Tab 可聚焦卡片，触屏轻触同样可播放，再次轻触可重播。保留系统减少动态效果与设置中关闭动效的静态呈现。删除入口层旧播放动作及其定时器，避免页面离开时保留演示回调。游戏状态与对局时钟不参与这些装饰动效。

触屏与触控笔通过委托的 `pointerup` 重置该卡片已有的 CSS 动画时间，不新增定时器或渲染循环。Chromium 已验证三张卡片鼠标悬停单次播放、离开复位、再次移入重播、键盘聚焦可见描边，以及 390 px 触屏模拟下首次轻触与再次轻触重播；系统减少动态效果和设置关闭动效时动画数量均为零。手机实机仍未执行。

本次最终 `npm run check` 通过，182 项测试无失败。浏览器另执行 `npm run check:browser -- e2e/game.spec.js --grep '手选、替换|教学实际练习'`，根/项目子路径的 390 px、320 px 与桌面共 6 项回归通过，覆盖手选、推荐、语言切换、构造时限及独立教学；中英文图示无旧播放按钮、无横向溢出或脚本异常。

后续修复点击后无法再次悬停重播：原先 `:focus` 在鼠标移出后依旧成立，已经结束的动画不会重启。改用 `:focus-visible` 触发键盘预览，触屏与触控笔使用独立的 `data-preview-active` 状态并在失焦时清理。没有增加定时器或游戏状态；增加浏览器回归覆盖点击后移入重播、Tab 聚焦、触屏重播和减少动态效果。

修复验证：修改前真实 Chromium 可复现点击后再次移入时十张牌和提示动画均停留在 `finished`。修改后点击留下普通焦点，但移出时动画为零，移入重新运行。`npm run check` 通过（182 项测试）；`npm run check:browser -- e2e/game.spec.js --grep '介绍图示点击后'` 在桌面项目子路径、320 px 项目子路径与 390 px 根路径全部通过，触屏、键盘与减少动态效果同时验证。
