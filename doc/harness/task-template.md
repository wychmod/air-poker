# 任务记录模板

用于中等以上改动；复制到本任务的文档目录后填写，小型修改可在交付说明中记录。模板本身不代表已批准需求。

## 目标与依据

- 用户要求与需要解决的具体问题：
- 当前可复现行为、相关代码与测试：
- 完成后可观察的行为：
- 涉及的提案与其评审状态：

## 范围与计划

| 步骤 | 涉及文件 / 职责        | 前置依赖     | 验证方式                   |
| ---- | ---------------------- | ------------ | -------------------------- |
| 1    | 明确本步修改位置与行为 | 无或前序步骤 | 输入、动作、预期输出或命令 |

说明本轮范围、已有修改的处理方式、数据或接口兼容问题。遇到需求实质变化时更新计划，并说明原因。

## 验收条件

- [ ] 目标行为有明确、可重复的检查方法。
- [ ] 规则或状态变更有相关回归用例；不涉及则说明原因。
- [ ] `npm run check` 通过。
- [ ] 按影响执行浏览器验收；没有执行的项说明原因。
- [ ] 工程文档与实际实现一致。
- [ ] Git 差异仅包含本轮预期范围；提交与推送符合用户授权。

## 实际验证与交付

| 项目     | 实际命令或步骤         | 结果与证据         |
| -------- | ---------------------- | ------------------ |
| 自动检查 | 记录本轮执行命令与时间 | 报告路径及失败原因 |
| 浏览器   | 记录浏览器、视口和交互 | 通过、失败或未执行 |

记录最终行为、剩余限制、后续工作，以及用户已要求的提交 / 推送结果。不得提前勾选未完成项。
