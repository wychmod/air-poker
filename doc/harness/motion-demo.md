# 动态漫画示例

## 目标与范围

用现有 manga-introduction-background.png 展示可在游戏内运行的原生实时动效。设置中“打开独立动态漫画示例”进入 motion-demo.html；返回链接回到首页。此页面是视觉样例，不代表其余页面提案已获采纳。

保留原图笔触，将左右人物作为独立裁剪图层；Canvas 绘制呼吸气泡、水光与浮尘。角色只有整体轻浮、轻旋转与视差，不包含面部表情、骨骼或逐根头发动画。

## 实现与职责

- motion-demo.html：展示场景、播放控件、原图对比与返回入口。
- styles/motion-demo.css：黑白漫画布局、人物图层、桌面及窄屏排版。
- browser/motion-demo.js：独立展示时间轴与生命周期，无运行模块依赖，属于现有 browser 层；不读取或更新游戏、计时或存储状态。
- index.html 与 styles/pages.css：仅增加首页示例入口。
- scripts/harness/config.js 与 scripts/serve.js：明确加入新 HTML，已有 browser、styles 与 assets/generated 清单覆盖其资源。

先完成画面与独立动画，再接入入口及资源白名单，最后做自动检查和浏览器验收。12 秒时间轴按指定时间绘制，支持暂停、重播、拖动、两档强度及原图对照。无需离线生成图片序列或编码视频。

## 验收条件

- 人物各自轻浮，气泡上升，水光随时间变化；循环衔接无跳变。
- 暂停后画面与视差冻结；拖动后准确停在所选时间，再播放接续。
- 原图对比完整展示输入素材，可返回动效；重播从头开始。
- 后台取消绘制，恢复不追赶隐藏时间；减少动态效果偏好默认暂停。
- 桌面与窄屏可操作，无横向溢出；控件可通过键盘使用。
- 首页进入与返回可用，普通开局仍可到达选牌阶段。
- 新页面及其资源进入静态产物并支持项目子路径。
