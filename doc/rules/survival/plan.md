# 失败、呼吸与耐息实现计划

## 模块与状态

新增 game/breathing.js 纯函数，保存每方正在呼吸的剩余毫秒、已开罐数和缺氧毫秒；未开罐仍位于 playerAir / aiAir。breathSpent 累计已打开罐数，供守恒核对。引擎接收带跨重开 sessionId 的绝对 elapsedMs；只接受递增、安全整数，按供气边界、上层截止、玩家下注 / CPU 截止依次推进，直到首次实际死亡冻结；一次大跳与分步推进等价。

新增 browser/match-clock.js 负责从单调时钟同步绝对对局时长，支持清理、挂起与恢复；不持有资金。入口在提交交互前同步时间，避免延迟回调越过死亡结算。气罐变化或阶段变化重绘，普通时间脉冲仅刷新呼吸文字，不丢失加注输入。

上层使用独立递增 attemptId、attempt 次数和 retry 标志。confirm-hand、fail-hand、upper-timeout 校验当前编号；双方失败重做不重新扣底注或下注。submit-hand 接受数组，错误请求类型不改状态；数组内错误牌、重复牌、已用牌、残缺或点数不符会记录该次失败。cards 校验完整实体成手；CPU 无合法成手时仍可打出自己的未用数字并记为失败。CPU 下注只读自己的失败状态和公开信息。

引擎保留 lower / upper / bet / showdown，新增 endurance。终局 winner 为明确结果；round-limit、no-betting-air、upper-deadlock 记录进入耐息原因。选牌或首次构造期间未开余额变为零，立即转耐息，保留当前供气，不进行零底注回合。供气终止时先退还未结算底池，再冻结终局，避免资金悬空。呼吸减少下注匹配上限时退回超出的未匹配投入，重新计算应跟额；退款可在缺氧宽限内恢复供气。快进与真实脉冲调用同一推进函数。

## UI 与时钟

沿用模板和现有 class，添加构造时钟、主动失败、重做及耐息快进入口。turn-clock 按阶段和编号区分构造 / 玩家下注 / CPU 延迟。app 统一调度，pageshow 先同步呼吸再同步行动。语言与只读查看不改变编号或起点。

## 验证

纯函数核对罐边界、长时间推进、同刻耗尽及分步等价；引擎核对单方失败、双失败重做、双无解、跨重开、时间重复、耐息胜者和账目；可控时钟核对后台与取消。浏览器验收主动失败、语言与计时、五轮或提前进入耐息及快进结果。
