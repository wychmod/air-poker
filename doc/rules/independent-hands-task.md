# 独立持牌修正任务

> 历史实施记录：其中按回合呼吸与整数 AIR 终局已由后续[实时呼吸与耐息](survival/spec.md)替代；当前事实以[现行规则](current.md)为准。

日期：2026-10-24。用户授权修正独立持牌，并联网核对原作规则与早期项目文档。

## 目标与范围

双方开局各持五张私有数字牌，在整局内逐张消耗。电脑在看到本轮玩家选择之前独立锁定自己的目标与成手；双方从同一个公共剩余实体牌库构造各自成手。修正当前每轮刷新目标、固定偏移电脑目标、固定模板选牌、私牌快照泄漏和部分用过牌继续比牌的问题。

联网依据与项目改编边界记录到同目录 `audit.md`，实际可玩规则记录到 `current.md`。本轮不改变 UI 风格，不接入待评审八页提案。现有单次下注自动匹配、回合间呼吸与按最终 AIR 结算仍作为明确的数字版简化保留，不能声称是完整原作下注规则。

## 验收条件与证据

- [x] 固定随机源下，改变玩家本轮目标/候选不改变 CPU 已锁定的目标/成手。
- [x] 五张目标只在开局生成；每轮双方各消耗一张，无法复用已用位置。
- [x] 相同数字也具有独立目标身份，不因数值相同一次消耗多个位置。
- [x] CPU 剩余数字、来源证明与摊牌前成手不出现在公开状态快照中。
- [x] 所有候选为五张不同、未使用的实体牌，点数和等于目标；支持 6–64。
- [x] 双方本轮可以选中相同实体牌，下一轮这些牌统一进入公共弃牌区。
- [x] 无合法目标时明确结算，不生成替代数字、不进入空候选页面。
- [x] AIR/底池守恒、重复动作、重开、完成回合数和终局边界通过回归。
- [x] `npm run check` 与桌面相关浏览器检查通过，记录实际证据。
- [ ] 完整窄屏交互与移动真机验收（工具限制，详见结果）。

## 验证结果

- 自动：npm test 21/21 通过；其中 150 局覆盖五类下注动作、AIR/底池/呼吸/灾厄账目、完整成手、终局与重开；另有确定性无合法目标提前结算用例。
- 独立性：固定随机源下穷举首轮五个目标和三个候选，CPU 公开数字及最终实体成手相同；数字重复位置分开消耗，快照无法篡改内部状态。
- 求解：全部 6–64 目标合法；与三组受限实体牌库的穷举最优结果对照通过；弃牌过滤后绝不返回残缺手牌。
- 完整 harness：npm run check 通过，24 个 JS 文件语法、9 层依赖、21 项回归、格式、构建、25 项本地资源 HTTP 检查通过；覆盖根路径与 /air-poker/，报告 output/harness/latest.json。
- 真实浏览器：Codex 内置浏览器，桌面 1265×720；从首页经过场进入游戏，初始玩家数字 41/33/40/43/21。第一轮选 41，CPU 独立公开 52；第二轮原五个数字保留，41 禁用，双方剩余四张，AIR 由 24/26 扣呼吸为 23/25。
- 桌面交互：切换候选、中英文与规则弹窗保留状态；五轮分别执行过牌、弃牌、加注、跟注、过牌。第五轮重叠两张，CPU 额外烧毁 5 AIR；最终玩家 24、CPU 13，完成轮数 5，弃牌 44 张。总 AIR 37 + 呼吸 8 + 实际烧毁 5 = 50；总结显示胜利。重开恢复 25/25、首轮、空弃牌，发出新数字。
- 浏览器日志：本次桌面局未捕获 error/warn。结果截图 output/browser/independent-hands-summary.png。
- 窄视口：使用真实浏览器 390×844 iframe 检查首页布局，截图 output/browser/narrow-home.png。当前 CUA 无法点击 iframe 内元素，完整窄屏选牌/下注/重开未执行；该检查不是移动设备模拟或真机测试。
- 未执行：移动真机、完整窄屏流程、后台恢复、禁用存储、30 秒超时和所有终局文案的逐一浏览器复现。这些保留在通用验收清单，不以自动测试或静态资源检查冒充浏览器通过。
