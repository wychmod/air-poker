## 早期规则有哪些问题

1. **实现偏差**：独立数字牌、整局不补牌和 CPU 不反选，早期设计本来写对了，修正前代码没有实现。这次修复的是实现缺陷。
2. **把自创机制混入原作描述**：“用过牌失效后残缺手牌继续比较”曾明确被设计成心理战扩展，但它与公开资料中的“使用已用牌判负”不同；不能当作忠实还原。本次移除，改为只提交合法完整成手。
3. **下注规则发生过错误改写**：取消半池加注限制、套用德州最小加注，没有获得本次查到的原作证据支持；“任一 check 结束”也不足以表达双方过牌的规则。
4. **数学表述必须带前提**：双方每人投入 s，正常败者净亏 s；灾厄再烧 s，总净亏 2s，恰等于等额下注时的底池。不能因此写成“损失整个底池再额外损失 s”。若剩余不足 s，本版只烧实际剩余量。
5. **随机生成与公平不是同一件事**：把 50 张实体牌分成十个证明成手、留两张，并平衡数字总和，是项目自定发牌法，不是已证实的原作强制算法；数字总和相近不保证牌型、灾厄风险或胜率公平，也不保证任意顺序都能完成五轮。
6. **上下层合并属于改编**：原作由不同角色承担上下层并限制信息。游戏让一名玩家同时看自己的数字与成手，不能据此反称“原作下层必然提前知道自己上层手牌”。
