# 当前可玩规则：数字版体验模式

更新：2026-10-24。本文描述当前代码，原作核对和证据见 [规则核对](audit.md)。本版合并上下层角色，下注采用轮流行动和半池上限，呼吸与终局仍有数字版约定，尚非原作完整复刻。

## 开局与两种牌

双方初始各 25 AIR，最多五回合。每方各有五张私有数字牌，开局生成一次，整局用后不补；重复数字按位置视为不同的牌。只能看自己的未出数字，界面仅显示 CPU 剩余数量和已公开数字。

实体扑克牌共用同一副 52 张牌，实体 ID 由点数和花色组成。每轮双方各从公共剩余牌库独立构造自己的五张成手，因此同轮可以重叠；不存在双方各一副互不影响的扑克牌。

数字牌生成采用项目规则：洗牌后分出十组五张证明成手，剩两张；枚举五对五分配，使双方数字总和差最小，再随机分配两侧。证明成手仅证明开局数字可解，不是预留手牌，也不会移出共享库。此方法不保证等胜率或任意出牌顺序下五轮都有解。

## 每轮选择

1. 回合开始时 CPU 仅依据自己的未用数字与公共弃牌，寻找合法推荐，并锁定当前最强牌型；同强推荐中随机选择。此时尚未收到玩家本轮数字或成手选择。
2. 玩家选择一张可用数字，双方各消耗一个数字位置，同时公开本轮数字。已经用过或当前无法组成五张合法成手的位置不能再选。
3. 玩家从至多三个合法推荐中选牌，确认后冻结。推荐覆盖最强牌型求解，但只是部分实体花色组合，不是所有策略方案；CPU 成手直到摊牌才公开。
4. 成手必须由五张不同且未用的实体牌组成，点数和等于自己的数字；A=1，J=11，Q=12，K=13。不得移除失效牌后比较残缺成手。
5. 双方各投入 min(回合数, 双方剩余 AIR) 底注，进入 30 秒下注。

牌型按标准五张扑克强弱比较；A 通常按高牌比较，A2345 顺子为五高。相同牌型逐项比较踢脚牌，不比较数字牌大小，也不以花色决定胜负。

## 多轮下注

首轮由公开数字较小的一方先行动；相同数字随机决定。第二轮起与上一轮先动方交替，不再重新按数字大小决定。双方已在确认成手时支付回合数底注；如果底注已耗尽一方 AIR，双方可追加的匹配空间为零，直接摊牌。

每次行动由当前一方独立支付自己的投入，另一方不会自动扣款。双方轮流选择：

- 过牌：仅应跟金额为 0 时合法。单次过牌不结束，两次连续过牌才摊牌。
- 跟注：仅有应跟差额时合法，准确补齐差额，然后换人继续；并不直接当成双方都过牌。
- 加注：先补齐应跟额，再增加 1 至当前最大加注增量。最小增量固定为 1，不要求达到上一次加注幅度。
- 弃牌：立即让对方收下实际底池；玩家和 CPU 均可弃牌，不追加灾厄。
- 可匹配全押：投入双方可匹配的总额上限，仍须满足半池加注限制；不能用全押按钮绕过上限。投入已匹配且一方剩余为零，直接摊牌。

设应跟额为 c，当前底池为 P，双方较高投入为 H，可匹配总投入上限 M=min(玩家已投+剩余, CPU 已投+剩余)。最大加注增量为 min(floor((P+c)/2), M−H)。加注实际支付 c+增量，全押实际支付 M−己方已投；不产生边池或负数 AIR。

例：双方底注各 1，玩家加 1；CPU 先跟 1 再加 2；玩家先跟 2 再加 4；CPU 跟 4，双方各投 8，底池 16；之后双方过牌结束。这与公开日文整理的首轮示例一致。半池的计算时点是补齐跟注后，AIR 向下取整、同数随机首动和可匹配全押属于本版明确约定。

CPU 只使用自己的锁定成手、玩家公开数字、公共弃牌和公开下注记录。它参考对方公开目标能组成的最强推荐牌型，再结合跟注价格、剩余 AIR 与加注压力作启发式选择，包含少量随机进攻；该评分不是实际胜率或完整博弈策略。不能读取玩家实际成手、候选选择和未出数字。

## 行动计时

每次轮到玩家有新的 30 秒，CPU 使用独立的 600ms 思考延迟。玩家无应跟额时超时自动过牌，有应跟额时超时自动弃牌；这是数字版超时约定。查看规则、语言切换或渲染不延长本次行动时间。后台恢复沿用原截止时间，重开清理旧时钟；每个动作携带跨重开递增的行动编号，陈旧按钮或回调不能对后续行动生效。

## 摊牌、弃牌与资金

- 普通胜负：胜者收回整个底池；双方等额投入 s 时，胜者净赚 s，败者净亏 s。
- 同轮实体牌重叠触发灾厄：非平局败者额外烧毁 min(自己的本轮总投入, 自己剩余 AIR)。这部分不转给胜者，界面显示实际烧毁量。
- 牌型完全相同：各自收回投入，不烧 AIR。
- 任一方弃牌：另一方收下底池，不追加灾厄惩罚。本版仍消费双方数字及已锁定成手，结算快照公开 CPU 成手并把双方成手并集放入弃牌；界面将弃牌方显示为牌背，这是数字版对弃牌处理的明确约定。
- 结算后双方成手并集进入公共弃牌，一张重叠实体牌只计一次，后续回合均不得再用。

正常结算守恒；灾厄仅损失实际烧毁量。进入下一轮前双方各扣至多 1 AIR 呼吸费，最多扣一次；没有下一轮合法选择时不扣这笔费用。

## 终局与重开

AIR 耗尽、已完成五轮，或一方没有能组成合法五张成手的剩余数字时结束。无合法目标时提前按 AIR 结算是数字版约定，不代表已实现原作上层失败/双方失败的特殊判例。最终比较剩余 AIR，多者胜，相同为平局；不补牌、不加赛、不用累计底池打破平局。

总结显示实际完成并已结算的回合数；未开始的回合不计入。重开发出一局新数字，恢复双方 25 AIR、空弃牌和首回合；语言切换、规则查看与渲染不重置对局。

所有状态变更通过引擎动作完成。公开快照不含 CPU 剩余数字、证明成手或未摊牌的锁定成手；这是前端模块边界，不是对本机调试者的加密保密机制。
