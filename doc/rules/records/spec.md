# 完整对局记录与空气账目

## 背景与目标

用户要求补齐完整对局记录与空气账目。现有引擎只保留最近七条日志和当前回合结果。沿用现行玩法与界面风格，为后续复盘提供真实事实；本轮直接按用户授权实施。

## 功能与验收

- F1 / AC1：记录整局已接受的选牌、候选、构造尝试、下注及超时、失败重做、耐息和终局；单调序号与实际对局毫秒，不截断为七条。
- F2 / AC2：逐轮保存起止余额、目标、弃牌前后、每次构造成手与原因、真实下注、比较依据、实际收到与烧毁；未完成及作废回合不冒充完成。
- F3 / AC3：每笔底注、跟注、加注、退款、结算、呼吸开罐与灾厄都有唯一账目，能够从初始各 25 罐重放到当前余额，逐笔保持总数 50。
- F4 / AC4：当前账目可读，未摊牌 CPU 成手与失败原因继续隐藏；局后记录完整，查询和导出不修改对局。
- F5 / AC5：完成局保存最近一局，重开不覆盖旧结果，刷新可查看；存储不可用、损坏或版本不支持时不阻断游戏，保留本次内存记录并可导出。
- F6 / AC6：沿用当前样式提供账目浮层、回合详情、完整时间线及 JSON 导出，中英文同步。只读查看不暂停呼吸或延长行动。

## 边界

不新增独立复盘页面、教学、多人联机、云同步或对局恢复。不保存未完成局为正式战绩；时间脉冲只记真实开罐，不每 250 毫秒写一条或写存储。既有未提交的生存逻辑继续保留。
