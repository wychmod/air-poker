# 空气扑克｜B 站宣传片制作方案

## 定案

主片《这局扑克，赌的是呼吸》，72 秒，1920×1080，30 fps，中文硬字幕，原创程序合成配乐与音效。音轨经软饱和控制孤立冲击峰值，再交由 FFmpeg 归一化。主片选择无旁白的音乐预告形式，字幕即叙事；另提供逐镜可录制口播文案。偏向推理、策略游戏、独立开发与漫画改编兴趣受众。没有实时 B 站受众调查，因此“最喜欢”不作为可证明结论；采用可验证的传播设计：前三秒明确危险、一个记忆点、可理解的规则反转、真实界面证明和单一试玩入口。

视觉方向：纸白、墨黑、局部暗红。大留白与密集线稿形成压力对比；人物局部裁切、镜头推进、分镜斜切、气泡、墨线、卡牌扇出与数字冲击由代码完成。原图不具备骨骼与表情层，本次采用视差和整体运动。禁止把旧整页效果图当实机；玩法图示标注“规则示意”，界面镜头使用本次真实浏览器截取。

## 美术与音频规范

- 主色 #f2f0e9 / #151515，风险色 #8d2429；红色同时配 −6、重叠框和文字，不单靠颜色。
- 中文标题使用本机宋体粗体感与雅黑粗体交替；数字使用 Bahnschrift。字体通过浏览器实际检查；不打包系统商业字体文件。
- 中央重要内容留在 x=120…1800，y=180…930。标题靠近顶部时保留足够弹幕空间；画面底部小号来源为补充信息，主要署名在终幕独立稳定展示。
- 固定随机种子的气泡、纸粒与音频噪声，所有动画使用绝对秒数；同一时间重绘像素一致，可拖动、暂停和离线逐帧导出。
- 原创算法音轨：120 BPM，低频心跳、颗粒气流、低音脉冲、短促敲击、悬念合成音；无下载商用歌曲、无仿某艺人声线。当前成片无旁白。可选外部配音轨以从零起点、对齐脚本的 WAV 输入。
- 响度目标 −14 LUFS、真峰值不高于 −1.5 dBTP，是本片混音目标，不宣称 B 站强制标准。双遍 loudnorm 测量并再次检测。

## 实现职责与制作顺序

1. scripts/promo/prepare.js：记录现有漫画素材来源、哈希与校验结果；生成规则示例 JSON，调用正式规则函数验证实体、目标和、牌型和灾厄账户。
2. promo/timeline.js：统一镜头、字幕、声音事件与总时长。字幕 SRT 从同一份数据导出。
3. promo/film.js：HTML Canvas 2D 绘制人物视差、水纹气泡、完整卡牌、数字转移、动态字幕和转场。提供 renderAt(seconds) 与 ready；不运行或改写正式对局。
4. promo/index.html、preview.js、style.css：响应式播放器、键盘控制、镜头定位、声音播放与拖动同步。减少动态偏好默认暂停；预览时间轴与游戏完全隔离。
5. scripts/promo/audio.js：生成 48 kHz 双声道 PCM 音轨，精确按时间线合成音乐和效果，可单独更换。
6. scripts/promo/render.js：启动本地白名单服务与 Chromium；等待字体、图片就绪，按 frame / fps 渲染；JPEG 高质量帧经 image2pipe 喂给 FFmpeg，编码无声 H.264 母版，测量/归一化音轨，再复用视频流封装 AAC。生成封面、分镜接触表、字幕、命令和渲染清单。
7. scripts/promo/verify.js：完整解码检查、帧数与时长、视频/音频参数、响度检测；与规则、时间线测试及真实浏览器检查互补。

FFmpeg 负责流式帧接收、H.264 编码、Rec.709 YUV420p 转换、音频归一化、AAC 48 kHz 合成、音画起点对齐和 MP4 faststart；HTML/JS 负责画面内容。固定 2160 帧避免真实录屏卡顿影响成片节奏。不把真实游戏时间加速写回引擎。
