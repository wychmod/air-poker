# 宣传片验收记录

2026-10-25。当前交付为《这局扑克，赌的是呼吸》72 秒中文音乐字幕版，无旁白。修改仅涉及离线制作工具、文档与检查范围，没有改动游戏规则或正式页面。

## 实际产物

- output/promo/air-poker-bilibili-72s.mp4：1920×1080、30 fps、2160 帧、72.00 秒，H.264 Main / YUV420p / Rec.709，AAC 48 kHz 双声道，约 37.1 MiB。
- 实测最终 AAC 综合响度 -14.79 LUFS，真峰值 -3.62 dBTP。以检测 JSON 的 input_i / input_tp 表示被检查成片本身，不能把探测滤镜拟议输出值误报为成片结果。
- 最初混音在 AAC 编码后出现短促噪声超峰；已通过原始音轨软饱和、10 kHz 低通和 192 kHz 过采样限幅修正。限幅器关闭自动补偿增益、启用前视延迟补偿，末端恢复 48 kHz。最终完整解码和响度检查均通过。
- 输出含封面 cover.png、逐镜 storyboard/、storyboard-contact.png、独立 SRT、score.wav、素材哈希和真实截图清单、FFmpeg 参数数组与验证 JSON。
- 主片的最后一次修改只涉及混音，使用 --audio-only 复用无声母版；代码在复用前校验时段、尺寸、帧率和帧数与清单一致。更动画面后必须正常渲染，不能复用旧母版。

使用随附 Playwright 1.62.1 / Chromium 151.0.7922.34；默认独立安装清单为 Playwright 1.58.2，本次未另行安装该版本验证。

- 实际打开游戏并通过按钮完成选数字、构牌、下注、摊牌、终局和复盘。固定浏览器随机种子 73 使素材便于复现，不注入伪造游戏状态。采集 home/build/bet/showdown/result/review 六张 1440×1080 截图，页面无脚本错误。
- 视频中三段实际界面明确标注“真实游戏界面 · 截图运镜”；它们不是连续交互录像。规则图示与时间压缩明确标注示意，不作为实际战绩。
- 工作台 1440×1000 实测播放、同步声音、暂停、镜头跳转、滑块定位、重播和键盘定位；390×844 无横向溢出。减少动态偏好默认暂停。
- 浏览器检验结果：9 项检查通过、0 页面错误。重复渲染 40 秒 → 5 秒 → 40 秒得到相同图像，验证任意拖动不会积累动画状态。
- 已目测 12 镜接触表、封面和从编码视频抽出的 12 帧；修正资源标签间距与片尾署名叠线。所有构牌/灾厄示例保留完整五张牌。
- 画面尺寸固定、时钟按 frame / fps 导出；本机渲染耗时不决定成片速度。没有将未测帧率作为移动设备性能承诺。
