# 竖屏宣传片 V2：中文旁白与音频迭代

执行日期：2026-10-26（Asia/Shanghai）。用户选择中文旁白主导、音乐退到背景。本次交付 30 秒中文旁白版、纯音频、同位置切换的 V1/V2 对比页、可重复执行的分轨制作代码。英文 TikTok 版仍为 V1 音乐字幕版。

V1 的响度与峰值已合格（−14.21 LUFS / −3.38 dBTP）。此次提升重点是叙事、分层与可懂度，没有把增加整体音量当作质量提升。画面视频包哈希与 V1 相同，因此听感对比不会受到画面重剪影响。

## 已完成的声音设计

- 旁白使用 Microsoft Edge 的 zh-CN-YunxiNeural 云希男声，AI 合成，rate +8%、pitch −2 Hz。九段口播合计约 20.21 秒，其余留给转折、声效与片尾；每段保留内部标点停顿，只裁首尾静音。
- 九段都以原生成语速落入窗口，实测 atempo=1.000。工具拒绝超过 1.16 倍的额外加速，遇到过长句子需要改写或重新合成；不截掉句尾。
- 配乐由独立音乐轨与音效轨组成。音乐保留 D 小调色彩与悬置和声，气流纹理贯穿水下感；15.4 秒开始收掉音乐，为“赢牌，未必赢局”腾出空间，18 秒重新进入，片尾主题回归。
- 音乐在人声期间平滑降低约 11.1 dB。句首前 100 ms 开始退后，句尾保留 60 ms，再用 420 ms 恢复，避免逐字抽动。音效以另一条侧链控制，保留关键冲击的节奏。
- 旁白做 90 Hz 高通和轻微低中频整理；配乐为讲话留出存在感频段。低音加入谐波是针对小扬声器的设计选择，实际手机外放效果尚未实测。
- 主音轨双遍响度归一化、过采样限幅、AAC 320k / 48 kHz 双声道。预览视频使用最终 AAC，纯音频从成片直接复制导出。

RMS 比值是分轨电平证据，不能替代语音可懂度的人工评价。对比页把 V1 再衰减 0.65 dB，让两版按照最终积分响度匹配；这个开关只影响试听，不改交付视频。
