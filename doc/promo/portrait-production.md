# 空气扑克｜抖音 / TikTok 竖屏宣传片

## 分析与创作选择

当前项目是原生 HTML/CSS/JavaScript 单人浏览器策略游戏，改编自迫稔雄《噬谎者》第 40–43 卷「空气扑克」篇。最容易在一次滑屏中记住的差异是：空气既是下注资源，也是后续呼吸；输掉有效且实体重叠的成手，还可能额外烧气。五张数字牌、自由构造五张实体牌、耐息终局提供第二层兴趣。复盘、推荐数量、半池加注公式适合游戏内教学，30 秒主片不堆叠所有细则。

主片 30 秒，1080×1920，9:16，30 fps；8 镜。输出中文抖音版和英文 TikTok 版，两版独立字幕、封面与真实界面素材。内容定位推理、策略、漫画和独立游戏受众；开场 0.6 秒内出现筹码与呼吸的联系，9.5 秒进入灾厄，15.5 秒抽掉鼓点形成反转，末尾用真实选择“加注还是留气”引导讨论。

这是基于短视频阅读场景的创作策略，没有本账号画像、实时热点或效果实验数据，不把“观众偏好”表述为确定排名。音乐与字幕可以独立理解；主片无旁白，另提供可录制口播稿。中文版针对中文观众，英文版使用短句与扑克术语，不声称英语自动带来海外传播。

## 画面规范

- 纸白 #f2f0e9、墨黑 #161616、风险暗红 #8d2429。保留漫画线稿、颗粒、分镜和水下气泡，镜头多为纵向揭示、纸片擦除、数字落点和成手重排。
- 1080×1920 画布以 x=72…882、y=180…1536 为主要信息安全区。右侧约 180 px、底部约 384 px 留给平台 UI；这是制作预留，不是平台永久统一规范。底部与右侧只放装饰。预览提供叠加遮挡模拟。
- 中文标题 100–160 px，英文标题 72–106 px；关键字幕 46–52 px；规则补充 30–36 px。在 360×640 等比例缩略图检查大标题、条件标签与 5 张完整牌。
- 五张牌统一横排在安全区；灾厄上下两行比较，各 5 张，不以三张局部牌冒充完整成手。牌型、目标和与烧毁额都来自已经验证的规则示例。
- 原有横图仅提取无 UI 的人物和气氛区域。人物是裁切图层整体运动，没有伪称独立表情/骨骼。实机截图按本次手机视口采集，截图上的数字保留原值。
- 字幕、牌面、符号、所有数字由 JS/Canvas 绘制，不烘焙在生成大图中。图像/字体就绪之后导出，固定随机种子与绝对秒数保证拖动可重复。

## 音乐与合成

原创程序音轨 140 BPM，32 分音符质感的短打击只用于转场，主节奏控制在半拍感。D 小调色彩的低音/短音动机、合成空气噪声、纸牌声、心跳构成 30 秒曲线，不使用热门商用歌曲或模仿特定艺人。旁白默认不加入，口播稿由分镜中文/英文列直接提供；工具支持外部从零对齐的配音。

两版使用相同拍点。统一 48 kHz 双声道，FFmpeg 双遍 loudnorm 目标 −14 LUFS（交付 ±1 LU），最终 AAC 真峰值不高于 −1 dBTP；过采样限幅保留峰值余量并补偿前视延迟。以编码后的实测值为准，不用原始 WAV 的峰值代替成片。

## 实现职责与顺序

1. 新建 portrait/timeline.js：8 镜、两种语言字幕、30 秒边界与安全区。
2. 新建 portrait/film.js：原生 HTML Canvas 画面、动态字、五张牌、空气账目、转场与封面；页面提供 renderAt(t)。
3. 新增独立竖屏预览控件与页面；键盘、拖动、字幕稿、语言链接与遮挡模拟。减少动态默认暂停，页面隐藏暂停。
4. 手机素材采集：实际点击选数字、构牌、下注/摊牌；中英两个页面独立完成，不读取隐藏对手数据。
5. 新建竖屏音乐生成器；导出器通过明确的 composition 配置选择画幅、时长、页面、音轨和输出目录，保留 72 秒横屏原有默认行为。
6. FFmpeg 接收逐帧图像，编码 H.264 / YUV420p / Rec.709，归一化与混音 AAC，固定时间原点、精确 900 帧、MP4 faststart。
7. 导出中文和英文 MP4、封面、SRT、8 镜总览、命令清单与验收记录；抽帧检查、完整解码、响度测量、手机尺寸与安全区检查。

本次不修改游戏规则或正式页面。视频制作文件不进入 dist/site/。横屏 V1 已归档文件不覆盖；本次竖屏交付保存独立目录，便于继续版本管理。
