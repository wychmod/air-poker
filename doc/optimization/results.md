## 自动检查

环境：Windows，Node.js 24.22.1，Playwright Test 1.62.1，Chromium 151.0.7922.34。生产环境没有新增包依赖。

- `npm run check`：最终通过语法、架构、134 项回归、格式、构建、资源预算与 HTTP smoke。当前环境通过同一入口 `node scripts/harness/check.js` 执行；日志为 `output/harness/optimization-final-check.log`，结构化结果为 `output/harness/latest.json`。
- `npm run check:browser`：构建后执行同一 Playwright 配置；最终 36 项通过、无失败或跳过。日志为 `output/harness/optimization-e2e-verified.log`；报告为 `output/e2e/report/index.html` 和 `output/e2e/results.json`。
- 浏览器项目：390×844 手机根路径；320×844 手机 `/air-poker/`；1280×800 桌面 `/air-poker/`。所有测试加载 `dist/site`，捕获脚本、控制台和 HTTP 错误。
- 核心交互使用真实引擎、页面点击/触控及实际下载文件；测试发牌采用固定随机源。语言/时限场景使用浏览器虚拟时钟。分享能力边界使用浏览器 API 替身，验证调用时机与降级契约。
- `git diff --check` 通过；核心 `game/` 和视频产物未改，用户已有 `.workbuddy/` 保留。宣传预览服务仅补充新资源目录和 WebP 类型支持。
