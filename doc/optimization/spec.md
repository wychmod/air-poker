# 游戏体验、浏览器回归与分享传播

用户于 2026-10-26 明确要求继续完成评审中的剩余优化，尤其是 CI 浏览器回归与分享能力。本任务以该指令作为实施范围授权。

## 功能与验收

- F1 手机构牌：目标、点数和、时限和锁定入口始终可达；推荐前移。AC1：320/390 像素、中英文、手选与推荐场景无需跨屏返回提交，草稿不丢失。
- F2 资源：发布只携带实际运行素材，首图压缩且提前加载。AC2：首页主图小于 300 KB，运行图片相对原始 10.72 MB 显著缩小，原素材保留，根路径/子路径都可加载。
- F3 初始化：首页不求解正式对局；首次开始只创建一次。AC3：首页/教学可独立使用，开始、重开、时钟及事件隔离通过回归。
- F4 教学：实际练习添牌、换牌、点数和错误修正及已用牌提示。AC4：用固定目标完成手动编辑与正确锁定，练习不触发正式对局。
- F5 浏览器回归：CI 在真实 Chromium 中验证手机构牌、下注、语言切换、归档刷新及分享；异常时留报告、截图、trace。AC5：浏览器命令在构建站点的根与项目子路径通过；主动破坏关键流程时会失败。
- F6 分享传播：静态摘要、分享封面、favicon；终局战报预览、PNG 下载、链接复制与支持设备上的系统分享。AC6：中英文胜/负/平战报来自已完成记录，展示结果、空气趋势、实际烧毁和原作来源；不暴露未完成局私牌；旧归档同样可分享；缺少系统分享/剪贴板能力时可下载/手动复制。

## 约束

保持原生 JS、零生产包依赖、现有白纸黑墨风格、游戏规则和信息隔离。视频继续原背景音乐且无旁白。保留源图和历史视频，不改写 Git 历史，不推送或部署。自动化测试为开发依赖；系统分享必须由用户点击触发。
